How to use the examples

  1. Fork-Profil: im Forge Datei → Vorlagen-Galerie → Datei importieren…, die JSON-Datei wählen und „Neues Profil aus Vorlage“ – danach Kodi-APK und Keystore wählen.
  2. Wizard und Repository: die ZIP in deinen Projekt-Ordner entpacken (Standard: Dokumente\sKulls Forge). Nach dem nächsten Start stehen die Projekte in den Bereichen Wizard bzw. Repository.
  3. Platzhalter wie DEINNAME und DEIN-REPOSITORY durch deine Angaben ersetzen und ein Upload-Ziel wählen – dann bauen.
  1. Fork profile: in the Forge choose File → Template gallery → Import file…, pick the JSON file and “New profile from template” – then choose the Kodi APK and keystore.
  2. Wizard and repository: unzip into your project folder (default Documents\sKulls Forge). After the next start the projects appear in the Wizard and Repository areas.
  3. Replace placeholders like DEINNAME and DEIN-REPOSITORY with your details and pick an upload target – then build.
