Häufige Fragen

Frequently asked questions

Kurze Antworten – ausführlich steht alles in der Anleitung.

Short answers – everything in detail is in the guide.

Allgemein

General

Was brauche ich zum Starten?What do I need to start?
Windows 10 oder 11. Das Setup bringt das fertig übersetzte Programm, Java und alle Werkzeuge mit – Python brauchst du nicht. Für Installationen auf Android-Geräten brauchst du ADB-Zugriff (USB-Debugging oder Debugging über WLAN).
Windows 10 or 11. The setup ships the compiled program, Java and all tools – you don't need Python. For installing on Android devices you need ADB access (USB debugging or wireless debugging).
Geht es auch portabel, z.B. vom USB-Stick?Can it run portable, e.g. from a USB stick?
Ja. Im Setup „Portabel entpacken“ wählen – alle Daten bleiben dann im Ordner der portablen Version, nichts landet in der Registry.
Yes. Choose "Unpack portable" in the setup – all data then stays in the portable version's folder, nothing goes into the registry.
Welche Kodi-Versionen werden unterstützt?Which Kodi versions are supported?
Kodi 18 bis 22. Für aktuelle Geräte empfehlen wir Kodi 20 oder neuer – Kodi 18/19 zeigen auf neuen Android-Versionen teils nur ein schwarzes Bild.
Kodi 18 to 22. For current devices we recommend Kodi 20 or newer – Kodi 18/19 partly show only a black screen on new Android versions.
Ist sKulls Forge ein offizielles Kodi-Produkt?Is sKulls Forge an official Kodi product?
Nein. Es nutzt offizielle Kodi-APKs als Grundlage. Mit dem Tool erstellte Forks müssen die GPL-Lizenz von Kodi einhalten.
No. It uses official Kodi APKs as its base. Forks created with the tool must comply with Kodi's GPL license.

Forks

Läuft der Fork neben dem normalen Kodi?Does the fork run next to regular Kodi?
Ja, mit eigenem Paketnamen ist der Fork eine eigene App mit eigenen Daten.
Yes, with its own package name the fork is a separate app with its own data.
Warum lässt sich ein Update nicht installieren?Why can't an update be installed?
Android installiert ein Update nur mit demselben Signatur-Schlüssel und einem höheren Version-Code. Der Forge merkt sich das Zertifikat und bricht ab, wenn ein anderer Schlüssel gewählt ist. Keystore-Sicherungen findest du unter Extras.
Android only installs an update with the same signing key and a higher version code. The Forge remembers the certificate and stops if a different key is chosen. Keystore backups are under Extras.
Wie bekommen meine Nutzer Updates des Forks?How do my users get fork updates?
Mit einer update.json-Adresse prüft der Fork beim Start auf neue Versionen. Ersatz-Server springen ein, wenn der Haupt-Server ausfällt. Der Build legt update.json, Download-Seite und QR-Codes neben die APKs.
With an update.json address the fork checks for new versions on start. Mirror servers step in when the main server is down. The build puts update.json, a download page and QR codes next to the APKs.
Kann der Fork mehrere Sprachen?Can the fork have several languages?
Ja: Startsprache und „Weitere Sprachen“ im Reiter Kodi-Einstellungen wählen – fehlende Sprachpakete lädt der Build aus dem Kodi-Repository. Der Einrichtungsassistent fragt die Sprache beim ersten Start ab.
Yes: choose the start language and "Extra languages" in the Kodi settings tab – the build loads missing language packs from the Kodi repository. The setup assistant asks for the language on first start.

Wizard

Was kommt nicht in einen Build?What is left out of a build?
Cache, Vorschaubilder, Addon-Pakete, Logs und Datenbanken, die Kodi selbst neu aufbaut – und standardmäßig alle Zugangsdaten. Die Größen-Analyse zeigt vorher, was wie viel Platz braucht.
Cache, thumbnails, add-on packages, logs and databases Kodi rebuilds itself – and by default all credentials. The size analysis shows beforehand what takes how much space.
Mein Build ist größer als 95 MB – geht GitHub trotzdem?My build is larger than 95 MB – does GitHub still work?
Ja. Große Builds lädt der Forge als Datei eines GitHub-Releases hoch (bis 2 GB); der Wizard lädt sie von dort.
Yes. The Forge uploads large builds as a file of a GitHub release (up to 2 GB); the wizard downloads them from there.
Funktioniert der Wizard auf allen Geräten?Does the wizard work on every device?
Ja – Android, Windows, macOS und Linux. Binär-Addons (PVR, Inputstream) lädt der Wizard nach dem Neustart passend zum Gerät.
Yes – Android, Windows, macOS and Linux. The wizard loads binary add-ons (PVR, inputstream) matching the device after the restart.
Wie finden Nutzer Hilfe im Wizard?How do users find help in the wizard?
Die Info-Taste (oder langes OK) erklärt jede Kachel. Unter Wartung → Logging lässt sich das Log filtern und ohne Passwörter auf USB oder ins Netzwerk speichern.
The Info key (or a long OK) explains every tile. Under Maintenance → Logging the log can be filtered and saved without passwords to USB or the network.

Hochladen

Uploading

Welche Server gehen?Which servers work?
FTP, FTPS, SFTP und GitHub (Repository mit GitHub Pages oder Releases). Upload-Ziele legst du einmal in den Einstellungen an.
FTP, FTPS, SFTP and GitHub (repository with GitHub Pages or releases). You set up upload targets once in the settings.
Der Upload brach ab – muss alles neu?The upload was interrupted – does everything start over?
Nein. Große Uploads werden beim nächsten Hochladen an der Abbruchstelle fortgesetzt.
No. Large uploads resume where they stopped on the next upload.
Woher weiß ich, dass alles online ist?How do I know everything is online?
Nach dem Hochladen prüft der Forge builds.json, Prüfsummen, jeden Repository-Zweig und jedes Addon-ZIP an der öffentlichen Adresse – bei GitHub Pages wartet er kurz, bis die neue Fassung da ist.
After uploading the Forge checks builds.json, checksums, every repository branch and every add-on ZIP at the public address – with GitHub Pages it waits briefly until the new version is live.

Sicherheit

Security

Wo stehen meine Passwörter und Tokens?Where are my passwords and tokens stored?
Nur in den Einstellungen auf deinem PC – nie in Profilen, Projekten, Builds oder APKs.
Only in the settings on your PC – never in profiles, projects, builds or APKs.
Welche Rechte braucht mein GitHub-Token?Which rights does my GitHub token need?
„repo“ (bzw. „public_repo“) – oder ein fein abgestuftes Token nur für die betroffenen Repositories, am besten mit Ablaufdatum. Der Forge warnt vor dem Ablauf und bei zu weiten Rechten.
"repo" (or "public_repo") – or a fine-grained token for just the repositories involved, ideally with an expiry date. The Forge warns before expiry and about overly broad rights.
Was macht die Sperrliste für Repositories?What does the repository blocklist do?
Sie verhindert, dass Addons aus unerwünschten Quellen in einen Build kommen. Unsichere Quellen (http, IP-Adressen, Kurz-Links) meldet der Forge zusätzlich.
It prevents add-ons from unwanted sources from getting into a build. The Forge also reports insecure sources (http, IP addresses, short links).
Ist der Quellcode öffentlich?Is the source code public?
Im Moment nicht.
Not at the moment.
