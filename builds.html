Build-Schaufenster

Build showcase

Kodi-Builds, die mit sKulls Forge gebaut und über einen Wizard veröffentlicht wurden – live aus der Build-Liste (builds.json) des Wizards, mit Bildern, Größe, Kodi-Version und Änderungen.

Kodi builds made with sKulls Forge and published through a wizard – live from the wizard's build list (builds.json), with images, size, Kodi version and changes.

Installiert wird ein Build immer über den Wizard in Kodi: erst das Repository hinzufügen, dann den Wizard installieren und dort den Build wählen. Die Anleitung dazu verlinkt jede Karte.

A build is always installed through the wizard in Kodi: add the repository first, then install the wizard and pick the build there. Each card links to the instructions.
